TypeFlow bundles a trimmed English vocabulary list derived from first20hours/google-10000-english/20k.txt for offline swipe typing. Upstream source: https://github.com/first20hours/google-10000-english. The upstream README describes the corpus source and use; no separate LICENSE file was present in the fetched upstream repository at integration time. Unicode emoji data is generated from Unicode Consortium emoji-test.txt, version 16.0 (2024-08-14): https://unicode.org/Public/emoji/16.0/emoji-test.txt. See Unicode terms of use: https://www.unicode.org/terms_of_use.html.
